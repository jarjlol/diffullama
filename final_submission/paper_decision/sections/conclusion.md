# Conclusion

A 4B decision model, prompted once with all ten candidates, is the only selector we tested that beats majority vote on GSM8K: 78.0% macro against 72.8% (+5.2 points, $p = 4.9 \times 10^{-6}$), with gains on both Dream and LLaDA. AR likelihood under Qwen2.5-7B stays more than 20 points below majority vote. Prompting the same model to choose a letter helps it, but only to 56.4%. On HumanEval the decision model chose a passing Dream candidate on every problem that had one, reaching the pass@10 oracle of 40.3% against 26.4% for running the docstring examples. A closed-book probe shows the model knows 37 of 40 GSM8K answers, and HumanEval memorisation was not tested. The defensible claim is therefore that a decision model can pick the correct candidate, not that it verifies reasoning or code. The next study should use problems the decision model cannot have memorised, such as procedurally generated puzzles or perturbed GSM8K variants. It should also run the HumanEval closed-book probe and add a second code model.
