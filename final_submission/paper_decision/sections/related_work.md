# Related Work

**Diffusion language models.** Masked diffusion models such as MDLM [sahoo2024mdlm] generate by iterative unmasking. Recent ones are large enough to solve math word problems: LLaDA [nie2025llada] is trained from scratch at 8B parameters, while Dream 7B [ye2025dream7b] and DiffuLLaMA [gong2025diffullama] are adapted from pre-trained AR checkpoints. Dream-Coder 7B [xie2025dreamcoder] applies the same adaptation to code. All of these models sample, so repeated draws for one prompt differ and a selection step can help.

**Selecting among samples.** Self-consistency [wang2023selfconsistency] samples several reasoning paths and takes the majority final answer. It needs no extra model, but it cannot recover a correct answer that is in the minority, and it is undefined for outputs without a short canonical answer, such as code. Trained verifiers [cobbe2021gsm8k] score each GSM8K solution with a model fine-tuned on correctness labels. For code, executing candidates on tests is the standard check [chen2021humaneval]; the docstring examples in each HumanEval prompt give a weak version of that check without the hidden tests.

**Selectors for diffusion models.** An outcome reward model trained on GSM8K reranks eight Dream-Instruct samples to 75.13%, against 60.05% for majority vote [zhan2026prm]. The training-free bidirectional-consistency score BMC picks among three LLaDA-Instruct samples at 77.8%, against 74.3% for self-consistency [ruan2026bmc]. Both use Instruct checkpoints and other prompts, so their numbers are not comparable to ours. Our decision model differs from both: it is not trained on GSM8K labels, it reads all candidates at once, and it returns one distribution over them in a single pass.

**Contamination.** GSM8K and HumanEval have been public since 2021, so any model trained on web data may have seen their problems and answers. A selector that already knows the answer can pick the candidate that carries it without checking the reasoning. We measure this for GSM8K with a closed-book probe and state it as untested for HumanEval.
